### D-001 — Объём инвентаризации этапа 00

Дата / автор / основание полномочия: 2026-09-17 / владелец процесса / указание в рабочей сессии: анализировать только нужные проекты.

Проблема: в рабочем каталоге много соседних проектов; пакет называет четыре материала (07 §1).

Варианты и последствия:

Принято: только материалы 07 §1. До указания исходники HUBTender были прочитаны точечно; они используются только для вопросов 07 §4. Для поиска материалов прочитаны заголовки README соседних проектов. Начатые обзоры других проектов остановлены, их результаты не использовались.

Статус: accepted

Что изменяет в требованиях/контрактах/тестах: сервис переговоров, хранилища и клиенты чата изучаются на своих этапах (07, 14, 16).
