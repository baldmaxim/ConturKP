## 3. Главное для архитектуры

1. **TenderHub не хранит неизменяемый снимок расчёта.** Версия тендера — отдельная строка `tenders`. Счётчики ревизий есть, но итог — последний пересчитанный, а не исторический снимок. «Закрытие по сроку» найдено только как блокировка редактирования в интерфейсе. Атомарную закрытую ревизию через текущий API получить нельзя (X-01).
2. **Ключ `tenders:read` не отдаёт состояние расчёта.** Нет ревизии, статуса расчёта, согласования ФП, lineage, событий изменений. Есть позиции, строки, `cached_grand_total`, `version`, `submission_deadline`.
3. **LocalAI фильтрует поиск только по источнику.** Фильтра по редакциям и набору источников нет. ID фрагмента строится из пути и номера чанка, а не из содержимого. Поиск по договору захватывает связанные тендеры. Авторизация — общий токен без ролей и тендерной изоляции; у адаптера Dify отдельный токен (X-04).
4. **Ценовой аудит LocalAI не годится как экономическая проверка.** Он сравнивает число из КП поставщика с коммерческими стоимостями и базовой ценой за единицу. Единица, количество, валюта, НДС и вид цены не учитываются (R-03).
5. **MailHub: API есть, машинного доступа нет.** Авторизация — cookie-сессия человека и CSRF. Общая лента скрывает отправленные. Цепочка отдаётся одной страницей без курсора. Message-ID и хэши вложений в ответ не входят. Вызов `opened` меняет прочитанность (X-03).
6. **RDWeb: подтверждён только формат экспорта по одному образцу.** Машинного API в материалах нет. LocalAI уже разбирает Markdown этого формата постранично, но `blocks.json` с координатами не читает (X-04, X-05).
7. **Переговоры: репозиторий и API не подтверждены** (Q-06).

### 4.4 Закупочные и коммерческие цены

- В строке сметы `unit_rate` и `total_amount` — себестоимость, `total_commercial_*` — коммерческая стоимость: `ApiTenderHub:AGENT_INSTRUCTIONS.md:56-68`.
- Источник цены поставщика хранится ссылкой `quote_link` и датами: `ApiTenderHub:ENDPOINTS.md:75-92`. Отдельной сущности предложения поставщика в API нет.
- Признака «цена с НДС / без НДС» на уровне строки в API нет: НДС — шаг наценки (4.2).
- Вывод: сравнивать цену из КП поставщика можно только с себестоимостью строки после сопоставления единицы, количества, валюты, доставки и НДС. Сравнение с коммерческой стоимостью даёт ложные расхождения на величину наценки (A19).

## 7. RDWeb

### 7.1 Образец экспорта: структура без содержимого

- Состав архива: PDF (77 страниц), `_results.md`, `_results.html`, `_blocks.json`.
- `blocks.json`: `schema_version` = 1, `document_id`, `document_name`, `document_path`, `generated_at`, `coordinate_space` = `normalized_page_top_left`.
- `pages` — 77 записей: `page_index` 0–76, `width_px`, `height_px`, `rotation`. Поворот 90° у 47 страниц, 0° у 30; распределение совпадает с `/Rotate` в PDF.
- `blocks` — 383 записи с уникальным `block_id`: `ordinal`, `page_index`, `page_label`, `block_type` (text 230, image 90, stamp 63), `shape_type` (rectangle 380, polygon 3 с `polygon_points`), `status` и `export_status` (все `recognized`), `coords_norm` из 4 чисел, `crop_url`.
- `crop_url` — внешний https-адрес одного хоста у 320 блоков, пусто у 63 штампов.
- `page_label` = `page_index` + 1 во всех блоках образца. Это номер страницы файла, не номер листа; номер листа — в штампе.
- `_results.md`: один заголовок документа, 77 `## Page N`, 320 `### BLOCK` (TEXT 230, IMAGE 90). Все 320 ID есть в `blocks.json`. Недостающие 63 блока — штампы: они выводятся строкой `**Stamp:**` (321 вхождение).
- У IMAGE-блоков есть производные поля: Summary 90, Description 90, Entities 90, Verification 71. Их можно отделить от исходного текста.
- Вывод: разница 320/383 объясняется штампами. Один образец не доказывает устойчивость схемы.

### 7.2 Неизвестные

Машинного API, авторизации, лимитов, idempotency, статусов, partial/final, версионирования схемы, связи hash оригинала с заданием, срока хранения crop URL и стоимости повторной обработки в материалах нет (X-05, Q-02).

Происхождение образца подтверждено: SHA-256 найденного файла совпал с архивом, который владелец приложил к задаче независимого ревью (`docs/reviews/00-review-1.md`). Открытыми остаются API RDWeb, другие варианты схемы экспорта, срок хранения crop URL и допустимость передачи документов (Q-02).
