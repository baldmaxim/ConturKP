## Решения при сведении

- Политика доступа ПК и отрицательные проверки ограниченного руководителя сохранены. В Office объединены ограниченный admin+manager и проверка manager /admin/operations → 403 с новыми тестами задач, диагностики и производительности Linux. Проверка /admin/office → 200 у руководителя сохранена.
- Исходный requirementsSchema.test.ts не менялся. Его дополнительные Linux-сочетания уже покрыты матрицей 24 сочетаний roleAccessIntegration.
- Принятый код outcome в DB/API, mapper, 15 tenderOutcome и форма TenderCard сохранены. Из Linux добавлены быстрые действия архива и возврата в списке/шапке с явным результатом.
- Сохранены обе версии идентичности распознавания: PDF renderingVersion и локальные wasm-кодеки ПК, XLSX parserVersion 2 Linux.
- UI ролей использует каталог и пользовательские коды string[]; серверная политика не заменялась.
- Перенесены история тендера и договора, общие материалы, версии и сравнение содержимого, наблюдение папок, Офис с задачами/диагностикой, почтовая пагинация и остальные доработки снимка.
- В двух новых фикстурах история меняет status и outcome совместно; тест архива ссылается на настоящую 0055 вместо старого номера. SQL-файлы миграций не менялись.
- Тесты двух раннеров подключены явно: Vitest собирает test.ts/test.mjs, пять node:test переименованы в node-test.mjs и запускаются npm run test:node. npm run test:all выполняет оба набора последовательно, Vitest с одним worker.

Браузерная проверка выявила отличие Linux: результат архивного тендера был только в title бейджа. Восстановлена видимая подпись, SSR-тест проверяет текст после удаления HTML-тегов. Сначала он дал 2/3 PASS с отказом на отсутствующем выигрыше, затем 3/3 PASS. Это отдельный коммит e6d7922 поверх интеграции 8299298.
