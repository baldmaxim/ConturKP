## Как реально исполняются службы

WinSW XML и CIM работающих процессов независимо подтвердили рабочий каталог `D:/ConturKP/app` и исполняемый файл `C:/Program Files/nodejs/node.exe`:

- `kontur-server`: `--env-file="D:/ConturKP/config/kontur.env" apps/server/src/main.ts`.
- `kontur-worker`: `--env-file="D:/ConturKP/config/kontur.env" apps/worker/src/main.ts`.

Это **нативное исполнение TypeScript в Node 24**, без tsx и без собранного серверного JS. Поэтому после точечной замены TS нужен штатный перезапуск обеих служб; отдельной серверной сборки и её отката в текущей конфигурации нет. Откат возвращает прежние TS-файлы. Повторно сверить XML, executable/arguments/cwd перед установкой; при смене режима запуска обновить манифест и включить реальные исполняемые JS-артефакты и их откат. Секреты env не выгружались.

В обоих XML stop timeout 30 секунд; он не заменяет ожидание конца работ. Остановить приём новых заданий и дождаться отсутствия выполняемых работ/записей **до** команды остановки. Не рассчитывать на принудительное завершение долгого задания этим таймаутом. Квитанция: `runtime/rollout-preflight-20261028/service-launch-and-node.json`.
