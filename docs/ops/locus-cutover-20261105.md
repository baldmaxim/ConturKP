# Минимальное переключение Locus — 05.11.2026

**DATA_CUTOVER_PASS_LOCUS_RUNTIME_OFF_L05_PENDING_OWNER_DECISION.** Данные перенесены в рабочий портал; процессы приложения Locus и его собственный автозапуск выключены. Старый Docker сейчас также выключен. Исходные данные и конфигурация сохранены. Основание — D-051 и [принятые L-01…05](../architecture/locus-minimal-retirement-20261102.md). Приёмка v1 и её прежние проверки сохраняют свои результаты.

## Состав переноса

- 1 608 оригиналов и связанных материалов, 79 производных текстов Locus и 10 реестров внешних исходников образуют 1 697 новых регистраций.
- У 79 исторических записей оригиналы физически отсутствуют. По конкретному решению владельца сохранён полный текст в обратимых CSV с явной отметкой «Оригинал не найден». Производные файлы не признаны найденными оригиналами.
- 303 неподдерживаемых для этой загрузки файла сохранены в исходных папках; они перечислены в десяти реестрах нужных договорных областей в портале. Исходные папки не удалялись.
- 80 старых синтетических записей исключены из делового реестра с явным решением. Исторические сведения и исходные кеши сохранены.
- После паузы обнаружены пять новых файлов в одной известной договорной группе. Их содержимое и родительский договор сверены, дополнение исполнено сначала в небольшой изолированной копии, затем в рабочем портале.
- Внесены шесть уточнений названий/примечаний. Четыре исторических структурных типа сохранены из-за неизменяемости первичной регистрации; назначение явно уточнено. Для двух прежних таблиц редакция не подтверждена. У одного нового расчёта расхождение нумерации приложения помечено в видимом названии.

После записи в договорном реестре не менее 37 договоров, 2 735 документов и 2 735 редакций. Прежние исторические записи и полномочия сохранены; операции переноса записаны в аудит.

## Текст и поиск

На момент ограниченного импорта: 475 запусков с полным текстом, 134 с частичным, 134 с ошибкой; 954 файла сохранены без нативного разбора. Для 609 запусков записано 41 311 поисковых фрагментов. Ошибки и неполнота видимы; обработка изображений и дальнейший OCR остаются обычной работой внутри портала. Очередь штатного построения индекса продолжена с существующей конфигурацией модели.

Полное слепое сравнение не менее 30 вопросов остаётся NOT_RUN/NOT_ACCEPTED в [бэклоге](../backlog.md); паритет ответов не заявлен. Историческое правило D-046 остаётся NOT_PROVEN с ранее принятым владельцем исключением из самостоятельных блокеров. Полный исторический протокол 19-A/19-B сохраняется отдельно.

## Копия и границы проверки

Текущая полная точка содержит 57 018 файлов; размер дампа 1,74 ГиБ. SHA-256 полного дампа прочитан независимо. Из него восстановлена полная схема до данных и семь договорных/контрольных таблиц; проверены все 2 708 целевых связей и шесть уточнений. Из самой копии прочитано 110 контрольных файлов, включая все 79 текстов, десять реестров и пять новых исходников.

Полное восстановление БД выполнено на подготовительном этапе до рабочего импорта. После импорта выполнено целевое контрольное восстановление без повторной загрузки всей почты и производных индексов. Дополнение из пяти файлов проверено с фактическими родительскими данными, полномочиями и полной схемой ограничений/триггеров. Полная копия БД для этого дополнения не заявляется.

Первоначальная пара полных обходов сохранена. После двухдневной паузы заново прочитан полный состав и метаданные файлов; прежние SHA наследуются только при неизменных File ID/размере/mtime/ctime. Все фактически переносимые байты независимо прочитаны импортом. Атомарный снимок файловой системы не заявляется.

## Хранение и возврат

Новых канонических объектов: 1 694, занято 11,37 ГиБ по уникальным NTFS File ID и выделенным блокам. Новые полезные данные резервной точки с дампом занимают 11,76 ГиБ; 54 928 файлов связаны с прежней управляемой точкой. Жёстких ссылок между новыми каноническими объектами и копией нет.

Собственные остановленные копии проверки убраны; частных планов, реестров и квитанций сохранено 0,52 ГиБ. Модели не копировались, исходные документы и прежние резервные точки не удалялись, retention не запускался. Свободно на момент замера: C — 95,44 ГиБ, D — 40,15 ГиБ. Наблюдаемое изменение D с начала продолжения 05.11: -23,74 ГиБ; оно включает параллельные записи портала и ОС.

Для возврата сохранены исходный проект Locus, его данные и десять неизменных файлов конфигурации. Контейнеры, образы и тома не удалялись. Из-за существующего сбоя запуска Docker Desktop контейнеры не удалось перечислить: их restart-policy не прочитана и не изменена. Работоспособность возврата через Docker после этого сбоя не подтверждена. Общий сервер моделей работает.

Настройка Docker AutoStart=false, но общая запись Windows Run для Docker Desktop остаётся; её фактическое включение и будущий запуск Qdrant после входа/перезагрузки не проверены. Три попытки запуска Docker закончились ошибками старых Windows IPC-конечных точек; после каждой Docker возвращён в выключенное состояние. Прежние нулевые IPC-объекты сохранены в двух отдельных каталогах; ремонт Docker не заявляется. Эти ограничения относятся к открытому L-05, а не к уже пройденным проверкам переноса и портала.

Точные пути, хэши, частные соответствия и порядок возврата находятся в локальных квитанциях задачи; в Git опубликованы только обезличенные результаты.
