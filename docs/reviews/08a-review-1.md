## R08a-01 — P1: старая редакция выдаётся как текущая при смешанных цитатах

Место: `packages/core/src/answers/claimChecks.ts:133–140`, последующая выдача — `renderVerifiedAnswer`.

Числа проверяются по всем документальным цитатам, включая `superseded`. Запрет текущего ответа срабатывает только если **все** цитаты заменены. Достаточно добавить одну текущую цитату, чтобы старое число прошло гейт.

Воспроизведение: E1 — «Срок оплаты составляет 30 дней», `superseded`; E2 — новая редакция пункта 3.1 со сроком 90 дней, `current`. Черновик: «Действующий срок оплаты составляет 30 дней», ссылки E1+E2, политика `current`. Результат: `passed: true`, `issues: []`, ответ «Действующий срок оплаты составляет 30 дней. [1][2]», outcome `confirmed`. Расхождение не выставлено. Проверяющая модель выключена — штатная допустимая конфигурация.

Ожидается: заменённая редакция не подтверждает действующее значение; наличие несвязанной текущей цитаты не отменяет запрет. Для исторического/сравнительного ответа нужна соответствующая трактовка, для актуального — проверка поддержки по актуальным основаниям. Добавить регрессионный тест смешанных цитат, а не только единственной старой цитаты.

Доказательство и повторяемый сценарий: `08a-review-1-mixed-version.log`, `08a-review-1-mixed-version.ts` (в исходной копии запускался из корня проекта).

## R08a-02 — P1: скрытый по текущим правам ответ попадает в историю модели

Места: `packages/db/src/answers.ts:266` (`previousTurns`), `apps/worker/src/handlers/answer.ts:194`; маршрут нового вопроса также вызывает `previousTurns` в `apps/server/src/routes/dialogs.ts:116`.

История выбирает текст всех завершённых ответов напрямую из БД. Текущие права на основания проверяются для нового evidence packet и для чтения ответа, но не для `previousTurns` перед отправкой истории модели.

Независимый API/worker тест: создать связанный договор Д-СЕКРЕТ с неустойкой 0,7%; получить подтверждённый ответ в диалоге тендерного этапа; отозвать `contract.read`, оставив `contract.link`. GET старого ответа корректно возвращает `visible: false`. Задать следующий вопрос по доступному ТЗ о фасаде. В захваченном запросе `answer_draft` текущий `evidence` уже не содержит Д-СЕКРЕТ, а `history` содержит полный текст скрытого ответа с Д-СЕКРЕТ. Все эти утверждения проверены тестом.

Ожидается: история для модели формируется с теми же текущими правами, что чтение сохранённого ответа. Скрытый ответ исключается либо заменяется безопасной отметкой без текста; запрет должен действовать до обращения к адаптеру модели. Добавить тест отзыва прав **между ходами**, проверяющий фактический вход модели.

Доказательство: `08a-review-1-findings.test.ts`, `08a-review-1-findings.log`. Тест «зелёный», потому что утверждает факт воспроизведения дефекта; он не является тестом корректного поведения.

Первоначальная гипотеза об утечке через `coverage.openQuestions` отклонена: parser сохраняет только количество вопросов, а не текст. В независимом сценарии дополнительно проверено, что непроверенная строка модели не выдана через API.
