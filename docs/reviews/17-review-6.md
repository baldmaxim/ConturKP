## 4. R17-10 — Ctrl+C при импорте Markdown оставляет каталог корпуса

**P2.** `scripts/ops/measure.ts:261` (создание `corpusDir`), `:423–429` (общая очистка), `:451–460` (обработчик сигнала). Корпус очищается только вложенным `finally` основного сценария, но не включён в список `tempDirs`, который использует обработчик Ctrl+C.

При сигнале обработчик дожидается своей `cleanup()`, записывает итог и вызывает `process.exit(1)`. Основной сценарий в это время может ждать импорт; его вложенный `finally` до выхода не выполняется. В результате база, хранилище и копия удалены, а `kontur-measure-md-*` с подготовленными PDF и ZIP остаётся. Это обычный Ctrl+C, не `kill -9` и не закрытие окна, для которых остатки оговорены как граница.

### Независимое воспроизведение на Windows

Сценарий `measure-lifecycle.py` запускает неизменённый `scripts/ops/measure.ts` в собственной скрытой консоли (`CREATE_NEW_CONSOLE`). Отдельный `console-ctrl-c.py` присоединяется только к консоли этого дочернего процесса и посылает настоящий `CTRL_C_EVENT`; `child.kill('SIGINT')` на Windows не используется, поскольку он принудительно завершает процесс.

1. Запустить синтетический профиль `--positions 3 --lines 2 --docs 1 --scans 0 --md-mb 20 --queries 1` с уникальным именем собственной БД.
2. Дождаться строки `# профиль md: 4 документов, 6827 страниц, Markdown 21 МБ` и подтвердить комментарий базы `kontur-measure:<метка запуска>`.
3. Послать Ctrl+C и дождаться завершения процесса.
4. Проверить базу и содержимое собственного TEMP до уборки фикстуры.

Оба запуска подтвердили остаток. Первый: `kontur-measure-md-rtoitW`. Повтор: `kontur-measure-md-oZOJzm`, **8 файлов, 7 882 847 байт**. В обоих код 1, в журнале `сигнал SIGINT` и `Итог: FAIL`, база удалена. В контрольном Ctrl+C до подготовки Markdown остатка нет. Ошибка — именно сохранённый каталог корпуса после штатной остановки; база сохраняется безопасно.

Доказательства: `outputs/independent-lifecycle.json` (3 успешных случая, 1 отказ), `outputs/independent-lifecycle-md-repeat.json` (тот же отказ), `outputs/lifecycle-ctrl-c-md*.log`. Остатки зафиксированы в JSON до удаления; затем обвязка удаляет только свой уникальный временный корень. Настоящих документов в нём нет.

**Требуется:** включать каталог корпуса в общую очистку сразу после создания и обеспечить её выполнение при штатном сигнале, в том числе во время подготовки/импорта корпуса. Сохранить защиту владения БД. Регрессия должна доходить до Markdown и проверять отсутствие `kontur-measure-md-*` после настоящего Ctrl+C; прежний тест без `--md-mb` этот случай не покрывает. На Windows штатный тест разработчика сейчас пропущен явно; это допустимо как граница теста, но не подтверждает очистку на целевой ОС.
