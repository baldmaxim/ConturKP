## Место и работающий Locus

Условия C приняты условно по D-049. READ ONLY замер БД —12 239 566 527 байт. Свободно 112 507 908 096, требуется 112 787 862 964 только для копии/БД/известного импорта/20 ГБ остатка, ещё без OCR. capacityFits=false; каталог/кластер/копирование не создавались. Из доступных локальных томов C/D/G ни один на момент проверки не покрывает эту нижнюю оценку; сетевые диски не выбраны автоматически.

Подготовлены assertIsolationLayout (PG и storage под одним target, включая junction) и checkIsolationReserve/withIsolationDiskGuard с 20 000 000 000 байт. Предстоящий исполнитель restore обязан подключить AbortSignal к операциям и остановить свой приватный кластер при ошибке; сам preflight ничего не копирует. Старый restore-check без контроля места в этих условиях не запускать. Размер текущей БД — консервативный измеренный ввод, не оценка по сжатому dump и не гарантия пикового места при построении индексов.

Для пишущего Locus заранее нужно согласованное окно без записи либо read-only snapshot. Нельзя игнорировать изменения cache/state ради PASS или останавливать Locus/общую модель самовольно. В этой работе службы не останавливались, реальная заморозка/новый пилот не запускались.
