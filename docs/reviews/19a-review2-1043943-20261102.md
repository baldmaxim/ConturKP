# Повторное независимое ревью подготовки 19-A

Владелец передал результат ревью 1043943: REQUEST_CHANGES только по R19A-03. Node 171/171 и typecheck прошли у ревьюера. Целостность ZIP, bundle, 27 Git-файлов и tree подтверждена. Частные корпусные числа на стороне ревьюера не воспроизводились.

R19A-01, R19A-02, R19A-04 и R19A-05 закрыты. R19A-06 закрыт для дерева 1043943; это не удаляет старый логин из уже опубликованного origin/main. Переписывание опубликованной истории отдельно не разрешалось и не выполнялось.

Оставшиеся требования R19A-03:

- INCLUDE_ORIGINAL требует договор и основание; группа относится ровно к одному договору; каждый включённый файл входит в предложения импорта.
- В форме нужны названия договоров, роль, номер редакции, SHA, размер, архивность и сведения об алиасах. Договор выбирается из каталога.
- Массовое принятие с одним основанием доступно только для единственной своей редакции без алиасов, архива и изменения размера. Прежние решения не перезаписываются.
- Загрузка черновика сохраняет дату; CLI принимает UTF-8 BOM с сохранением SHA точных исходных байтов.

Сбор реальных решений владельца остаётся приостановлен до принятия R19A-03. Отдельно перед гейтом A нужна оценка подписанных алиасов: старый auditLocusCorpus отклоняет TARGET_REUSED, его проверки в этой правке не ослаблены. Публикационный кандидат 2f4084a ревьюер не проверял, разрешения push нет.

Место: прежний полный вариант на C не проходит. Ревью допускает другой том либо отдельное изменение расчёта для нескольких томов. Условие D-049 не считается изменённым одним фактом перечисления альтернатив.
