# LibreOffice и шрифты для комплекта (этап 12)

ADR-013, D-032 В-12-2. Комплект собирает worker: генерирует DOCX/XLSX по размеченной копии образца и переводит каждый файл в PDF-превью через LibreOffice. Без конвертера комплект не собирается (`converter_unavailable`). Если шрифта образца нет в системе, он подменяется другим, и сборка тоже не проходит (`font_substituted`). Версия конвертера записывается в кандидат и манифест.

## Установка

Windows (целевой ПК и ревью):
1. Установить LibreOffice (стабильная ветка, 64-бит) в каталог по умолчанию `C:\Program Files\LibreOffice`. Worker сам найдёт консольный вход `soffice.com` в `PATH` или в этом каталоге. Другой каталог задаётся в `.env` ключом `SOFFICE_PATH=<полный путь к soffice.com>`. Если указан `soffice.exe`, а рядом есть `soffice.com`, используется `soffice.com`: через оконный `soffice.exe` определение версии не завершается (R12-01).
2. Шрифты образцов должны быть установлены для всех пользователей, в том числе для учётной записи службы worker. Демонстрационные формы используют Liberation Serif и Liberation Sans: LibreOffice ставит их сам. Реальным формам нужны шрифты, указанные в самих образцах (обычно Times New Roman, Calibri, Arial). Их список даёт проверка `fonts_embedded` в карточке комплекта.
3. Перезапустить worker.

Linux (машина разработки):

```bash
sudo apt install libreoffice-writer-nogui libreoffice-calc-nogui fonts-liberation
soffice --version     # проверено: LibreOffice 26.2.5.2
```

## Проверка

```powershell
npm run config:check                  # SOFFICE_PATH: «задано / не задано» (значение не выводится)
node artifacts/stage-12/page-review.mjs <каталог для PNG>
```

`page-review` генерирует обе демонстрационные формы с длинными текстами и таблицами и переводит их в PDF. Страницы сохраняются в PNG для просмотра человеком, итог пишется в `artifacts/stage-12/page-review.log`: число страниц, встроенные шрифты, подмена (должно быть «нет»), остатки разметки.

Тестам этапа 12 нужен настоящий конвертер. Путь для тестов задаётся `KONTUR_TEST_SOFFICE`, иначе ищется как у worker. Без конвертера тесты падают с понятной причиной.

## Ограничения

- Отрисовка LibreOffice близка к Word, но не тождественна: переносы и разрывы страниц могут отличаться. Заказчику уходят DOCX/XLSX, PDF остаётся внутренним превью (D-032 В-12-1). Поэтому страницы реальных форм проверяет человек (D-032 В-12-10).
- Конвертация идёт с временным профилем: локаль ru-RU, загрузка внешних ресурсов документа и макросы запрещены (S12-04). Тайм-аут — `OFFICE_CONVERT_TIMEOUT_SECONDS` (по умолчанию 120). Профиль удаляется после каждого файла. Сетевой изоляции на уровне ОС нет: worker стоит на целевом ПК в локальной сети (ADR-011).
- Формулы XLSX порталом не пересчитываются: в превью видны значения, сохранённые в образце.
