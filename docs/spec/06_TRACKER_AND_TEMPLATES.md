```markdown

Дата / автор / основание полномочия:

Принято:
```

Технический выбор в рамках требований может принять разработчик. Изменение обязательного бизнес-процесса нельзя выдать за ADR разработчика.

## Папки разработки

```text
docs/spec/                 исходный пакет
docs/adr/                  архитектурные решения
docs/stages/               отчёты разработчика
docs/reviews/              независимые проверки
docs/integrations/         контракты и статусы
docs/runbooks/             эксплуатация и восстановление
fixtures/                  только синтетические/обезличенные данные
artifacts/stage-XX/        проверяемые тестовые результаты, без секретов
```

Git ignore должен исключать production-файлы, секреты, dumps и пользовательские документы. Пути живых данных выбираются конфигурацией и не зашиваются в код.
