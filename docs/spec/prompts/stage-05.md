# Этап 05 — Интеграция LocalAI и поиск по версиям

Продолжай проект «Контур КП». Прочитай docs/spec/01_PRODUCT_SPEC.md, актуальные ADR, docs/project-state.md, предыдущее независимое ревью и применимые инструкции репозитория. Если пакет находится в другом каталоге, найди его по именам файлов. Выполни только указанный ниже этап. Не начинай следующий. Все инварианты I01–I19 обязательны. Отчёт — по docs/spec/06_TRACKER_AND_TEMPLATES.md; проверки — с учётом docs/spec/05_ACCEPTANCE_CASES.md. Не объявляй fixture рабочей интеграцией. Передай точный проверяемый коммит в независимое ревью Codex.

Подключи LocalAI как индекс/поиск через документированный API. Используй готовые материалы RDWeb без повторного OCR. При необходимости подготовь отдельное задание на API импорта, фильтрацию по document revision/source-set и стабильные ссылки; не меняй соседний репозиторий незаметно.

Реализуй точный поиск обозначений, полнотекстовый и доступный смысловой поиск, привязку цитат к неизменяемым фрагментам. Фильтруй по правам и версиям до выбора top-k. Не позволяй linkedContractId расширять поиск за пределы выбранного выпуска. Полный реестр документов/требований доступен отдельно от поиска.

Результаты можно выдавать напрямую без генерации LocalAI. Локальное предварительное распознавание явно маркируется; недоступность RDWeb не означает тихого равнозначного fallback.

Проверки: два тендера с одинаковой фразой; два этапа с противоположными ответами; перепривязка договора; новая индексация не ломает старую цитату; удаление текущего индекса не уничтожает оригинал; отсутствие результатов не становится утверждением отсутствия требования.

Выход: поиск на закреплённом комплекте, точные источники, реальный статус адаптера. Если существующий API не поддерживает изоляцию, этап не принимается до решения.
