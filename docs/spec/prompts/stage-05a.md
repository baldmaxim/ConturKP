# Этап 05a — Локальное распознавание форматов вне охвата RDWeb

Продолжай проект «Контур КП». Прочитай docs/spec/01_PRODUCT_SPEC.md, актуальные ADR, docs/project-state.md, предыдущее независимое ревью и применимые инструкции репозитория. Если пакет находится в другом каталоге, найди его по именам файлов. Выполни только указанный ниже этап. Не начинай следующий. Все инварианты I01–I19 обязательны. Отчёт — по docs/spec/06_TRACKER_AND_TEMPLATES.md; проверки — с учётом docs/spec/05_ACCEPTANCE_CASES.md. Не объявляй fixture рабочей интеграцией. Передай точный проверяемый коммит независимому ревьюеру.

Заведи движок `local_ocr` рядом с `rdweb_export`, не подменяя его. `recognition_run.engine` это значение уже допускает. Покрой текстовый слой PDF, `.docx`, `.xlsx`, `.csv` и сканы без текстового слоя. Происхождение фрагмента различай: извлечённый текст документа и распознанный текст — разные значения `origin` (I06). Класс ресурса — по ADR-004 §7b: извлечение текста и CPU-распознавание — `default` с низким приоритетом, движок на GPU — `gpu` по протоколу слота; отдельного класса `ocr` без полного протокола `resource_slot` не вводи. Строки листа `.xlsx` получают якорь листа и строки — от него зависят случаи 10, 14 и 15 манифеста Locus (`docs/architecture/locus-regression-manifest.md`).

Задание локального распознавания не ставится на редакцию, у которой есть или ожидается завершённый прогон RDWeb; пришедший позже прогон RDWeb перекрывает локальный через существующий `supersedes_run_id`. При автоподборе прогона в снимок области локальный никогда не выигрывает у RDWeb. *Уточнение D-024 (2026-09-30): маршрут PDF — явная политика документа `auto` / `local` / `rdweb`, fail-closed (OD-1); «ожидается прогон RDWeb» — идущий прогон RDWeb или политика `rdweb`; при `auto` PDF распознаётся локально только явной командой человека. Закрытый перечень форматов — PDF, DOCX, XLSX, CSV, иначе `unsupported_format` (OD-4); итог прогона — `complete` / `needs_review` / `failed` (OD-6); выбор прогона — функция БД `recognition_preferred_run` (AD-05a-3); у логических единиц (лист, таблица, тело документа) пиксельных размеров нет (AD-05a-1).*

Координат у этих форматов нет: интерфейс показывает текст и якорь страницы и прямо пишет, что координаты недоступны, а не рисует рамку наугад. Признаки неполноты и непригодного текста пишутся в качество прогона; страница, не прошедшая порог, не даёт статус «полностью».

Проверки: A43 — явная маркировка качества и происхождения без тихой подмены основной обработки; скан без текстового слоя; повреждённый файл; внешний конвертер упал или вернул пусто; повторный прогон того же файла.

Выход: движок `local_ocr` и обработка уже доступных редакций документов тендеров в форматах вне охвата RDWeb. Договорной корпус появляется на этапе 06a, почтовый — на этапе 07: когда источник появится, его редакции ставятся на локальное распознавание автоматически по формату или явной командой, без повторной реализации движка. RDWeb остаётся основным распознаванием проектной документации.
