# Этап 16 — Чат через Codex и Cursor

Продолжай проект «Контур КП». Прочитай docs/spec/01_PRODUCT_SPEC.md, актуальные ADR, docs/project-state.md, предыдущее независимое ревью и применимые инструкции репозитория. Если пакет находится в другом каталоге, найди его по именам файлов. Выполни только указанный ниже этап. Не начинай следующий. Все инварианты I01–I19 обязательны. Отчёт — по docs/spec/06_TRACKER_AND_TEMPLATES.md; проверки — с учётом docs/spec/05_ACCEPTANCE_CASES.md. Не объявляй fixture рабочей интеграцией. Передай точный проверяемый коммит независимому ревьюеру.

Расширь/подключи общий MCP для портала, переиспользуя собственный поиск портала (этап 05). Второго MCP-сервера нет: семь инструментов Locus сливаются с инструментами ADR-010, вопрос к ответному ядру наружу не выставляется — клиент сам является моделью. Реализуй явный scope: tender, stage/release или два releases для сравнения. Ограничивай объём ответа, pagination, права и аудит инструментов. Суммы вычисляются сервером, источники имеют стабильные ссылки. Поиск идёт через прогон поиска: `search_evidence` создаёт прогон, `get_search_run` дочитывает итог; предварительный лексический результат за итоговый не выдаётся (`docs/contracts/mcp-tools.md`). Если этап 06a уже принят, вид контекста `contract` доступен и через MCP. Закрой случаи манифеста Locus со статусом `deferred:16`.

Инструменты чтения: выбрать дело, документы/цитата, смета/экономика, вопросы/решения, готовность, сравнение. Инструменты записи: только создать предложенное замечание, вопрос, условие или причину с идемпотентным request ID. Нет approve/release/send/admin или произвольного SQL/shell/filesystem.

Подготовь настройку Codex и Cursor по актуальной официальной документации; не объявляй прочитанный пример конфигурации успешным подключением. Включи сценарии проверки обоих клиентов. Если Cursor пока не установлен/недоступен, отдели проверенный протокол от live client gate. Встроенный чат из подписки не реализуй.

Проверки: неоднозначный тендер; исторический вопрос; отсутствие цены; неверный вид цены; citation не существует; инструкция «игнорируй правила» в PDF; запрос чужого тендера; запись от модели не становится решением; повторный request не дублирует замечание; секреты не уходят в result.

Выход: чат отвечает с основаниями на контрольные вопросы и может сохранять только предложения. Новая сессия не теряет историю продукта.
