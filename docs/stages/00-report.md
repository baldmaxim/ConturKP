## Непроверенное

- Живые API TenderHub, MailHub, LocalAI, RDWeb не вызывались. Нельзя утверждать, что развёрнутые сборки совпадают с прочитанным кодом.
- OpenAPI развёрнутого TenderHub не запрашивался (R-06).
- Отсутствие серверной проверки срока в TenderHub установлено поиском, не полным аудитом; в архитектуре сохраняется эта оговорка.
- Маршруты агента MailHub (незакоммиченные правки) и семантика курсора ленты не изучались.
- Возобновление заданий LocalAI и постраничный статус через API не проверялись.
- Поворот страниц RDWeb сверен с PDF только по распределению, не постранично. Схема подтверждена одним образцом.
- Сервис переговоров, хранилища, клиенты чата, целевой ПК не изучались.
- `verify_discovery.py` проверяет существование диапазонов строк, а не истинность утверждений; шаблоны секретов не исчерпывающие. Число успешных проверок не заменяет содержательное ревью.

- D-001: объём сужен владельцем во время этапа. Начатые фоновые обзоры двух соседних проектов остановлены, результаты не использовались.
- D-002: использованы найденные копии материалов. Происхождение образца RDWeb и архива API подтверждено совпадением SHA-256 с вложениями владельца (ревью 00-1); вопросы API и схемы RDWeb остаются в Q-02.
- D-003 (proposed): ветка `stage-00`; push выполняет владелец.
- Во время этапа владелец попросил разработать `BRAND.md` с логотипами и визуальным стилем через дизайн-агента. Это вне этапа 00: работа выполняется отдельным коммитом в отдельной ветке и в область этого ревью не входит.
