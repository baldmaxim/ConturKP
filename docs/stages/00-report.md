- Живые API TenderHub, MailHub, LocalAI, RDWeb не вызывались. Нельзя утверждать, что развёрнутые сборки совпадают с прочитанным кодом.

- Отсутствие серверной проверки срока в TenderHub установлено поиском, не полным аудитом.
- Маршруты агента MailHub (незакоммиченные правки) и семантика курсора ленты не изучались.
- Возобновление заданий LocalAI и постраничный статус через API не проверялись.
- Поворот страниц RDWeb сверен с PDF только по распределению, не постранично. Схема подтверждена одним образцом.
- Сервис переговоров, хранилища, клиенты чата, целевой ПК не изучались.
