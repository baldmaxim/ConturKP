## Непроверенное

- Код не написан: ни одно проектное решение не подтверждено работающей реализацией.
- Внешние API не вызывались; контракты X-01…X-05 — проект, не согласованный с владельцами соседних систем.
- Конкретные версии библиотек (Express, React, схемы, десятичная арифметика, MCP SDK) не зафиксированы и не проверены на совместимость.
- Способ разбора чисел JSON без промежуточного `float` выбран как требование, но не проверен тестом (этап 06).
- Транспорт и версия спецификации MCP не сверялись с официальной документацией (этап 16).
- API Яндекс Диска, способ сверки содержимого и служебная учётная запись SMB не изучались (этап 14).
- Производительность, SLO, размер хранилища и восстановление не измерялись (этап 17); на машине разработки нет GPU и мало свободного места (U-08).
- Матрица блокеров, набор уровней критичности и правило итога КП — предложения до ответов Q-09, Q-05.

## Решения и отклонения

- ADR-001…ADR-011 со статусом `proposed`: принимаются вместе с этапом после независимого ревью.
- D-004: ответы владельца (валюты `RUB`, `USD`, `EUR`, `CNY`; рабочее название на время разработки; обязательное согласование со смартфона) внесены в модель денег и план тестирования.
- D-005 (proposed): ветка `stage-01` создана от принятого `stage-00`, так как слияние в `main` не выполнялось.
- **Требует внимания ревью:** ADR-008 §7 размещает точный и полнотекстовый поиск по фрагментам в PostgreSQL портала, а не в LocalAI. Обоснование — отсутствие в LocalAI фильтра по редакциям и стабильных ID (`docs/discovery.md` §5.2) и требование полноты прохода (спецификация §12).
